**What I do on a mission**

- **CI/CD** — pipelines that run on every push, build once, promote the same
  artifact, and keep secrets out of the repository.
- **Containers & deploys** — small multi-stage images, pinned bases,
  healthchecks; releases you can roll back, migrations that expand before
  they contract.
- **Observability** — a health endpoint, structured logs, errors that reach a
  human, an uptime check from outside.
- **Cost guardrails** — a provider hard limit and a billing alert *before*
  launch, not after the first surprise invoice.
